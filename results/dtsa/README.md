# results/dtsa/

DTSA-core runs on the Taillard job-shop instances (random-key encoding, no local search).

| File | Contents | Regenerated by |
|---|---|---|
| `dtsa_jssp.csv` | Job-shop runs, sampler C1 | `dtsa/run_jssp.py` |
| `dtsa_jssp_c3.csv` | Job-shop runs, sampler C3 (the resolved setting) | `dtsa/run_jssp_c3.py` |
| `dtsa_table5.csv` | Per-instance summary (runs/mean/median/min/max/std) in the shape of Şahman Table 5 | `dtsa/make_dtsa_table5.py` (from `dtsa_jssp_c3.csv`) |
| `dtsa_jssp_system_config.json` | Machine/software configuration recorded at run time | written alongside the runs |

`dtsa_table5.csv` is a **descriptive per-instance summary prepared as input for any separate
statistical analysis** — it is not itself a statistical test. Regenerate it exactly with:

```bash
uv run python dtsa/make_dtsa_table5.py
```

The DTSA-vs-ATSA advantage figures quoted in the report are computed from these CSVs by
`dtsa/metrics.py` (the single source of every derived number).
