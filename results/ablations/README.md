# results/ablations/

Diagnostic and ablation runs behind specific findings in the DTSA report.

| File | Question it answers | Regenerated by |
|---|---|---|
| `mwkr_ablation.csv` | Is DTSA's advantage from search, or from the MWKR-seeded start? (5 instances, C1) | `dtsa/run_mwkr_ablation.py` |
| `b4_atsa_seeded.csv` | What happens if ATSA is given the same one MWKR tree? (5 instances, C3) | `dtsa/run_b4_atsa_seeded.py` |
| `sampler_sensitivity_c3.csv` | How much does the symmetry sampler (C1 vs C3) matter? | `dtsa/run_sampler_sensitivity.py` |
| `u1_rescore.csv` | Re-score of the sampler candidates with the corrected start city | `dtsa/run_u1_rescore.py` |
| `partb_residual.csv` | What is the unspecified TSP start city worth? | `dtsa/run_partb.py` |
| `n5_diag.csv` | Why does the N5 local search find almost nothing? (ta01, ta71) | `dtsa/diag_localsearch.py` |

All are seeded and reproducible. Commands are listed in the DTSA report, §7.
