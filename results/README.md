# results/

Every CSV here is a committed experimental result. Layout:

| Folder | What | Regenerated by |
|---|---|---|
| `atsa/` | ATSA runs on the Taillard instances (ta01–ta80), 20 seeds each | `run_atsa_campaign.py`, `python -m atsa_jssp.cli run` |
| `dtsa/` | DTSA-core job-shop runs + per-instance summary | `dtsa/run_jssp.py`, `dtsa/run_jssp_c3.py`, `dtsa/make_dtsa_table5.py` |
| `ablations/` | MWKR / sampler / seeding / residual diagnostics | `dtsa/run_mwkr_ablation.py`, `run_sampler_sensitivity.py`, `run_u1_rescore.py`, `run_partb.py`, `run_b4_atsa_seeded.py`, `diag_localsearch.py` |
| `timing/` | ATSA-vs-DTSA runtime and contention timings | `dtsa/run_timing.py`, `dtsa/run_atsa_timing.py`, `dtsa/run_timing_recheck.py` |
| `gate1/` | TSP validation gate (see that folder's README) | `dtsa/validation_tsp/run_gate1.py`, `analyse_gate1.py` |
| `sweep/` | ATSA operator/config sweep + a TSA bisection | see below |

**Regeneration.** Every CSV in `atsa/`, `dtsa/`, `ablations/`, `timing/`, and `gate1/` is produced
by a script in this repository (the table above). The exceptions are the **eight** archived
operator-sweep CSVs in `sweep/`, which have no committed generator; `sweep/tsa_bisect.csv` is
regenerable. See `sweep/README.md`.

**Not committed (regenerable diagnostics).** Three large trace files from the ATSA sweep were left
out to keep the repo small: `convergence.json`, `traces.json`, `instrumentation.json`. They are
per-run diagnostic dumps, not results; regenerate them by re-running the sweep with tracing enabled
(see `sweep/README.md`). No headline number depends on them.
